# 선택하지 않은 프로필 사진이 나타나는 문제

이전 `voiceroom_my_avatar` 키는 사진만 저장하고 닉네임 소유자를 기록하지 않았습니다. 입장/자동 복원 시 이 사진을 현재 닉네임에 붙였고, 방의 전체 사진 동기화는 다른 접속자가 가진 과거 닉네임 사진까지 다시 적용했습니다. 퇴장 후 사진 항목도 남았습니다.

- 새 `voiceroom_my_avatar_v2` 기록은 `{nick, avatar}`로 저장하고 정확히 같은 닉네임에만 복원합니다. 소유자를 알 수 없는 기존 기록은 자동 복원하지 않습니다. 기존에 직접 설정했던 사진도 새 버전에서 다시 선택해야 할 수 있습니다.
- 닉네임 변경 버튼으로 직접 바꿀 때는 본인이 선택한 사진만 함께 옮깁니다. 일반 새 입장이나 다른 닉네임에는 넘기지 않습니다.
- 방을 연결할 때 사진 상태를 초기화하고, 상대가 입장/최종 퇴장하면 이전 닉네임 사진을 정리합니다.
- 원격 사진은 SDK가 확인한 발신자 본인의 닉네임에만 적용합니다. 다른 사람이 동기화한 제3자 사진, 특히 내 닉네임의 사진은 받지 않습니다.
- 유효한 이미지 데이터만 받으며 8 Mi 문자 상한을 적용합니다. 저장 공간이 차단된 브라우저에서도 입장과 현재 접속 중 사진 선택은 동작합니다.

검사: `node scripts/check-avatar-profile.mjs` — 소유자 없는 이전 사진, 다른 닉네임, 명시적 이름 변경, 새로고침 복원, 타인의 사진 덮어쓰기, 잘못된/과대 데이터, 저장소 오류.
