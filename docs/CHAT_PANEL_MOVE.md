# 채팅창 이동

채팅창 위쪽 **실시간 채팅** 제목 부분을 마우스로 드래그하거나 터치로 끌어 이동한다. 메시지 목록은 기존처럼 스크롤하고, 입력란·접기 버튼을 눌러도 드래그를 시작하지 않는다.

- 옮기면 제목 오른쪽에 원위치 아이콘이 나타난다.
- 이 브라우저에 위치를 저장하며 새로고침·재입장 시 복원한다.
- 접기·펼치기는 이동한 위치에서 유지한다. 펼치거나 화면이 줄어 채팅창이 밖으로 나가면 안쪽으로 보정한다.
- 제목에 키보드 포커스를 두고 방향키로 12px, Shift+방향키로 40px 이동한다. Home은 원위치다.
- 드래그를 시작하는 5px 이동 전에는 자리를 바꾸지 않는다. Pointer Capture로 제목 영역 밖까지 끌어도 이동을 이어간다.
- 포인터 이동마다 방 전체를 React로 다시 그리지 않고 패널 좌표만 갱신한다. 종료 시 최종 위치를 반영한다.
- 위치 저장 키는 `voiceroom_chat_position_v1`이며 개인 브라우저에만 저장한다. 방 참가자에게 이동 위치를 전송하지 않는다.

구현: `lib/use-draggable-chat.ts`, `lib/floating-panel.ts`. 기존 채팅 DOM을 유지해 입력 초안·스크롤·반응·첨부 동작을 보존한다. 떠 있는 채팅창은 발화석 창 및 방 제목보다 앞에 표시하고, 모달보다 아래에 둔다.

검증: `node scripts/check-floating-panel.mjs`의 36개 위치/크기 조합 및 저장값 검증, 대상 파일 ESLint, TypeScript 및 프로덕션 빌드 통과.

ego-browser의 로컬 프로덕션 목업에서 실제 포인터 드래그, 저장/새로고침 복원, 원위치, 방향키/Home, CDP 터치 드래그, 390×844/390×420 화면, 접기/펼치기, 입력 초안 유지와 제목 겹침 순서를 검사했다. 테스트 초안은 전송하지 않았다. 실제 아이폰 Safari에서의 검증은 하지 않았다. 브라우저 화면 캡처 API는 시간 초과가 발생하여 좌표·DOM 상태와 실제 입력 이벤트로 결과를 확인했다.
