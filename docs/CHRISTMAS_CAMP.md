# 크리스마스 캠핑 라운지

설정 → 지도·배경 → **크리스마스 캠핑 라운지**에서 선택한다. 사용자가 승인한 간결한 새 시안으로 교체했다. 저장된 지도 ID `christmas_party`는 유지하며 지도 리비전은 4이다. `/christmas-garden`의 공개 미리보기도 같은 지도를 표시한다.

밤바다 캠핑 라운지와 같은 1672×941 고정 월드, 카메라 방식, 캐릭터 확대율 1를 사용한다. 테두리 수풀·바위와 큰 리본을 줄이고 눈바닥을 넓고 매끈하게 정돈했다. 설산·울타리·가장자리 나무·입구 등불은 바닥 배경에, 큰 트리·텐트·코코아 부스·피크닉 두 곳·모닥불·의자 여섯 개는 투명 PNG 12개에 분리했다. 사물은 발 기준으로 캐릭터와 깊이 정렬하며 별도 바닥 충돌 다각형을 사용한다.

의자는 각각 한 명만 앉는다. 클릭 → 앉기를 누르면 걸어가서 착석하고 기존 앞뒤·사선 방향 전환을 사용한다. 좌판 접점과 발 위치를 새 그림에 맞췄다. 텐트는 걸어 들어가는 별도 실내 공간으로 연결하며 입구·복귀 위치는 (305, 430)이다. 새 그림에 보이는 피크닉 방석 4개에도 앉을 수 있다. 코코아 부스는 외부 사물이다. 산타 루미와 눈 놀이 기능은 `CHRISTMAS_PLAY.md`를 참고한다.

트리 실제 전구를 감지해 기존 공유 시계로 3초 주기의 연속 밝기 변화를 적용한다. 눈과 녹색 가지는 조명 마스크에서 제외한다. 모닥불은 새 투명 이미지 안에 빛·불티를 그리며 배경을 비틀지 않는다. 기존 해변 모닥불의 월드 기준 위치는 유지한다.

## 그림 및 제작

- `public/plaza/christmas-camp-v2/concept.png`: 사용자가 승인한 GPT 원본 시안.
- `ground.png`: 중심 사물을 제거한 빈 바닥 배경.
- `foreground-source.png`: GPT가 그린 실제 알파 사물 원본의 희미한 배경만 제거한 결과.
- `assets.json`: 12개 사물의 원본 좌표·크기. 각 개별 PNG는 이 좌표에서만 잘랐다.
- `layer-preview.png`: 실제 바닥과 투명 에셋의 합성 미리보기.
- `artwork.json`: 생성 프롬프트, GPT 모델·도구, 출력 파일 해시 및 수동 분리 단계 기록.
- `alpha-cleanup.json`: 스프라이트젠의 `clear_haze(floor=64, edge=2)` 보고서. 불필요한 희미한 픽셀 75,788개를 지웠고 사물의 실체·윤곽 픽셀은 바꾸지 않았다.

스프라이트젠 `gen --provider codex --model gpt-5.6-sol`로 시안·바닥·투명 사물 세 장을 생성했다. 투명 사물은 `--transparent --alpha-mode native`를 지정했다. `scripts/split-christmas-camp.mjs`의 수동 소유 영역은 AI가 이미 그린 알파 픽셀을 게임 사물별로 나누고 투명 여백을 정리하는 작업이며, 스프라이트젠 애니메이션 추출 결과라고 제시하지 않는다. 기존 캐릭터 동작 이미지에는 변경이 없다.

## 검증

`check-room-seating.mjs`에서 모든 등장점, 12개 실제 알파 레이어·원본 종횡비, 여섯 좌석의 접근·이탈 경로, 모닥불·트리 충돌, 한 자리 동시 예약 제한, 원격 착석 자세를 검사한다. 조명 감지와 밝기 진행은 `check-festive-lights.mjs`, `check-festive-light-clock.mjs`로 확인했다. NPC 기본 회귀 검사와 타입 검사·프로덕션 빌드도 수행한다.

로컬 프로덕션 브라우저에서 지도 선택, 13개 이미지 로딩(바닥+사물), 실제 트리 조명 밝기 진행, 모닥불 프레임 진행, 남서 의자로 걸어가 사선 뒤보기 착석(1/1명), 390×844 모바일 상태를 확인했다. 브라우저 화면 캡처는 `Page.captureScreenshot` 오류로 완료하지 못했으며 시각 미리보기는 별도 합성 PNG를 사용한다. 실제 방에 입장하거나 사용자의 마이크를 사용하지 않았다.
