# 크리스마스 광장 AI 아트 교체

기존 SVG 지형·트리·오두막·가로등과 재사용하던 벤치·소나무를 GPT 이미지 6종으로 교체했다. `sprite-gen gen --provider codex --model gpt-5.6-sol`의 기존 구독 경로를 사용했다. 바닥을 먼저 만든 뒤 각 투명 소품이 바닥을 스타일 참고 이미지로 사용하도록 했다.

원본·프롬프트·생성 보고서는 로컬 `sprites_run/christmas-v7`에 보존한다. 투명 소품은 sprite-gen의 native alpha와 trim-alpha를 사용했다. 배포용 파일은 원본 해상도의 무손실 WebP이며, PNG와 재디코딩한 WebP의 RGBA 픽셀이 모두 같음을 검사했다. 리사이즈나 수작업 보정은 하지 않았다.

| 그림 | 네이티브 픽셀 |
|---|---|
| 눈과 돌길·광장 | 1586×992 |
| 장식 트리·선물 | 895×1509 |
| 오두막 | 1362×1013 |
| 가로등 | 419×1505 |
| 2인 벤치 | 1364×950 |
| 눈 쌓인 소나무 | 886×1417 |

맵 크기는 2880×1800을 유지한다. 바닥은 화면 배경, 소품 25개는 각각 깊이 순서가 있는 레이어다. 소품의 실제 종횡비로 표시 크기를 계산하고 줄기·선물·건물·벤치의 충돌을 맞췄다. 벤치의 두 착석 목적지는 유지하고 새 벤치의 그림 위치와 가림 기준을 조정했다.

`ChristmasLights`는 원본의 따뜻한 전구/창문 픽셀을 찾아 그 위치에만 광채를 추가한다. 트리 96점, 가로등 6개의 각 9점, 오두막 2개의 각 30점이 서로 다른 위상으로 빛난다. 트리에는 작은 반짝임과 떠오르는 금빛 입자를 더했다. 원본 그림 자체를 확대·이동시키지 않으며, 모든 빛은 해당 소품과 같은 월드 좌표와 가림 순서를 사용한다. 모션 줄이기 설정에서는 빛을 정지 상태로 표시한다.

## 확인

- TypeScript 및 프로덕션 빌드, 변경된 독립 모듈 ESLint.
- `check-festive-lights.mjs`: 투명 여백·눈·잎을 빛으로 선택하지 않는지, 광점 개수와 밝기 범위, 시간에 따른 밝기 변화, 배포 에셋 크기 검사.
- `check-room-seating.mjs`, `check-garden-navigation.mjs`: 2인 착석과 예약 해제, 양쪽 지도 스폰·의자 목적지, 충돌·우회 경로 검사.
- 실제 로컬 방에서 조명 9개가 모두 디코딩되고 픽셀이 시간에 따라 바뀌며 원본 소품 크기는 유지됨을 확인했다. 모션 줄이기 상태에서는 픽셀이 바뀌지 않았다.
- 새 벤치에 걸어가 앉는 모습과 1/2 점유 표시를 확인했다. 390×844 모바일 화면에서 채팅과 하단 패널이 분리되는 것도 확인했다.
- 전체 배치 미리보기는 실제 로컬 방의 이미지·프레임 좌표·조명 캔버스를 읽어 만든 QA 보드다. 별도 기기의 실제 통화 검증은 수행하지 않았다.
