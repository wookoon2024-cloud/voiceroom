# 지도·착석·모바일 UI 개선

- 정원 연못을 정규화 Y +0.07만큼 내려 배경 중앙에 배치했다. 물 애니메이션·가림 순서·충돌 영역을 함께 이동했다.
- 상태 배지와 말풍선 높이에 캐릭터별 확대율과 앉기/눕기 자세를 반영해 머리를 가리지 않도록 했다.
- 설정 버튼의 중복 톱니바퀴를 없애고 설정창을 360px 폭의 화면·공간, TTS, 오디오, 방 관리 영역으로 정리했다.
- 채팅 입력줄의 귓속말 선택 버튼과 대상 목록을 제거했다. 상대 메뉴의 채팅 귓속말, 현재 대상 배너와 전체 대화 복귀는 유지한다.
- 7명 모두 바닥에 양반다리로 앉기, 의자에 걸터앉기, 누워 쉬기 그림을 추가했다. 기존 GPT 구독 방식의 sprite-gen으로 21행·84프레임을 생성하고 공식 extract → compose-atlas → preview → inspect를 거쳤다. 모든 행은 실제 서로 다른 그림 4개가 있다. 호흡/깜박임을 위한 대기 자세여서 inspect의 일반 움직임 임계치 경고는 허용했다. 원본과 검수 결과는 로컬 `sprites_run/rest-v6`에 보존한다.
- 쉬는 자세는 별도의 REST_STATE로 유지되며 말하기가 덮어쓰지 않는다. 이동·점프·상호작용·일어나기·퇴장으로 해제한다. 바닥 앉기와 의자 앉기는 다른 atlas와 표시 배율을 사용한다.
- 정원 의자 4개, 크리스마스 의자 8개는 각각 두 좌석을 제공한다. 의자 클릭 → 앉기 → 장애물을 피해서 걸어가기 → 착석 순서다. BENCH_CLAIM으로 이동 중부터 예약하고 동시 요청은 시각/ID의 고정 순서로 두 자리만 남긴다. 타이브레이크는 기기 언어에 영향을 받지 않는 문자열 비교다. 이미 앉은 사람의 좌석이 재조정되면 새 자리로 다시 걸어간다. 이동, 내리기, 연결 종료 및 재접속 시 예약을 정리한다. 중앙 서버 잠금 대신 신뢰 전송과 동일한 참가자별 예약 해석을 사용하는 구조다.
- 캐릭터 모드의 눈/하트 등 효과는 카메라로 이동하는 월드 안에 그린다. 기본 모드에서는 기존 화면 효과를 유지한다.
- 2,880×1,800 크리스마스 맵을 추가했다. 큰 트리, 조명이 있는 오두막과 가로등, 중앙 광장·외곽 모임 장소·의자·산책길을 별도 SVG/PNG 레이어로 구성했다. 트리 줄기와 건물·의자는 통과하지 못하고 수관은 가림 레이어로 동작한다. 지도 전환 시 중앙 안전 지점으로 이동하며 카메라가 본인을 따라간다. 기존 캐릭터의 화면상 크기를 줄이지 않는다.
- 모바일 채팅과 하단 버튼을 하나의 세로 레이아웃에 놓아 겹치지 않게 했다. 좌석은 가로 스크롤, 입력 글자는 16px, 채팅 접기는 42px 높이다. 키보드 입력 중에는 하단 버튼을 숨긴다. 입력 중 채팅 버튼을 눌러도 포커스 변화 때문에 버튼이 먼저 이동하지 않도록 처리했다.

## 확인

- TypeScript, production build, 변경된 독립 모듈 ESLint.
- `scripts/check-room-seating.mjs`: 3명 동시 예약, 2명 제한·두 좌석 분리, 도착/원격 앉기, 이동 시 해제, 눕기 토글, 잘못된 예약 무시, 양쪽 지도의 스폰/의자 위치 충돌 검사.
- 기존 7명 로스터, 원격 상호작용 재생, 픽셀 클릭, 경로 검사와 `check-solo-actions.mjs`의 반복 동작·쉬기 렌더링 검사.
- 실제 로컬 방에서 걸어가 의자에 앉기, 만석 버튼 비활성화·해제, 혼자 앉기/눕기 유지, 상대 메뉴에서 채팅 귓속말 진입을 확인했다.
- 390×844 화면의 채팅·하단 패널 분리와 400px 높이로 줄인 키보드 상태에서 입력란 노출, 상태 배지가 머리 위에 표시되는 것을 확인했다. 하트 캔버스의 좌표가 카메라 이동에 맞춰 월드와 동일하게 이동하는 것도 확인했다.
- 별도 실제 휴대전화와 실제 다중 기기 통화 검증은 수행하지 않았다. 기존 접속자는 새 패킷과 지도를 사용하려면 새로고침이 필요하다.
