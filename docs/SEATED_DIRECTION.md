# 앉은 방향 전환

앉은 캐릭터에 마우스를 올리면 머리 위에 **앞보기 / 뒤보기** 버튼이 나타난다. 팝업을 열지 않고 바로 방향을 바꾼다. 모바일은 앉은 캐릭터를 터치하면 표시하며, 키보드 초점으로도 접근할 수 있다. 클릭해서 여는 내 동작 팝업에는 방향 선택을 두지 않는다. 의자와 바닥 앉기를 모두 지원하며, 눕기에는 표시하지 않는다. 방향 전환은 `REST_STATE.direction` (`down` / `up`)을 같은 방에 공유한다. 의자 예약, 자리 좌표, 로컬 시작 시간은 유지하고 새로운 이동 요청을 만들지 않는다. 늦게 입장한 사용자에게 보내는 `syncOwn`에도 포함된다. 이전 패킷에 방향이 없거나 유효하지 않으면 앞보기로 읽는다.

11개 캐릭터에 각 4프레임 `up_sit`, `up_floor_sit` 행을 추가했다. `public/plaza/back-seating-v1/<character>/`의 `manifest.json`과 `sprite-sheet-alpha.png`를 사용한다. 정면과 동일한 캐릭터·앉기 배율을 적용하고, 텍스처만 실제 뒷모습으로 바꾼다. 원래 정면 그림이나 의자 배치는 바꾸지 않는다.

생성은 기존 **sprite-gen GPT 이미지 행** 경로 (`--provider codex --model gpt-5.6-sol`)를 사용한다. OpenAI API 과금 경로를 사용하지 않는다. 동일한 기존 캐릭터 기본 이미지를 참조하며, 최종 요청문은 [generate-back-seating.py](../scripts/generate-back-seating.py)에 있다. 주요 지시: 완전히 옷을 입은 기존 캐릭터가 화면 위를 향해 이미 앉아 있는 뒷모습, 얼굴 노출 없음, 벤치에 앉기와 바닥에 앉기, 일정한 체형·머리 크기·접지선, 미세한 호흡 4프레임, 가구·그림자·배경 없음. 추출·알파 정리·아틀라스·GIF·검사는 기존 엔진 단계로 수행하고, 수동 등분 자르기나 정면 좌우 반전을 사용하지 않는다.

재현: 스프라이트젠 전용 venv의 Python으로 `scripts/generate-back-seating.py`, 이어서 `scripts/finish-back-seating.py`를 실행한다. 중간 결과와 생성 로그는 `sprites_run/back-seating-v1/`에 둔다. 완성 자산만 public에 복사한다. `scripts/check-room-seating.mjs`는 방향 공유·재동기화·예약 유지·걷기 요청 없음·바닥 앉기·눕기 제외와 모든 뒤보기 행을 검사한다. `scripts/check-sprite-paint.mjs`는 실제 뒷모습 행 사용 및 방향 전환 전후 동일 배율을 검사한다.

검증: 11종의 두 행(88개 프레임)을 확인했다. 뒷모습, 의복·종별 정체성, 전신, 미세한 호흡 자세와 반복 연결을 확인했고, 별도 보행 동작으로 주장하지 않는다. 각 실행의 엔진 `inspect`가 통과했다. 착석/공유 검사는 전체 휴식 220프레임, 렌더러 검사는 154개 조합을 통과했다. 로컬 mock 브라우저에서 의자로 걸어가기, 1/1 점유, 앞→뒤→앞 전환, 일어나기 후 0/1 해제, 바닥 뒤보기(`up_floor_sit`), 의자 재착석을 확인했다. TypeScript·대상 ESLint·프로덕션 빌드도 통과했다. 실제 참가자에게 메시지를 보내거나 방을 새로고침시키지 않았다.
