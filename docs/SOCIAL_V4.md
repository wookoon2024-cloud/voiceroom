# 정원 비율·수면 및 상호작용 6종

- 벤치를 15% × 18%에서 8% × 9.6%로 축소. 중심과 발 위치를 유지하고 가림 기준과 충돌 사각형도 축소했다.
- 충돌선 ON/OFF 디버그 버튼과 오버레이를 제거했다. 실제 장애물 충돌과 경로 탐색은 유지한다.
- 연못은 원본 물 텍스처를 작은 파형으로 왜곡하고 물결·중앙 물줄기·낙하 물방울을 30Hz로 그린다. 물 픽셀 마스크로 돌과 잎의 움직임을 막는다. 시스템의 동작 줄이기 설정과 비활성 탭을 존중한다.
- 장난 펀치, 하이파이브, 악수, 쓰다듬기, 선물 주기, 함께 춤추기를 추가했다. 두 캐릭터 각각 send/receive 12개 상태, 합계 24개 상태·152프레임. 192×240 전신 셀, 발 기준과 월드 좌표 고정. 손이나 소품 동작은 실제 새 이미지 프레임이다.
- 메뉴·접근 거리·재생 시간·수신 메시지 검증은 `lib/social-actions.ts`를 공유한다. 상대에게 장애물을 돌아 걸어간 뒤 공통 시작 시각으로 실행한다.
- `/character-lab`에서 8가지 상호작용과 4가지 캐릭터 조합을 확인할 수 있다.

## 에셋과 제작

`public/plaza/social-v4/{cute_male_v2,strong_male_v2}/{manifest.json,sprite-sheet-alpha.png}`.

기존 승인된 캐릭터 베이스를 참조하여 sprite-gen의 `prepare → gen-set --provider codex --model gpt-5.6-sol → extract → compose-atlas → preview_animation → inspect`를 사용했다. 추출·정렬·아틀라스는 엔진 결과이며 별도 수작업 프레임 편집은 없다. 로컬 `sprites_run/social-v4`에 요청·프롬프트·원본·검수 시트와 미리보기가 있다. `pairs.py`는 검수용 조합 이미지만 만들며 원본을 수정하지 않는다.

쓰다듬기는 손의 높이를 수정해 다시 생성했고, 근육질 캐릭터의 선물 보내기는 전달 후 빈손이 되도록 다시 생성했다. 각 동작은 준비→접촉/반응→복귀로 검토했다. 춤은 무한 반복 대신 함께 짧게 춘 뒤 종료한다. 가상 선물은 장식용이며 결제·아이템 보관 기능은 없다.

## 확인

- sprite-gen 두 캐릭터 전체 상태 추출·검사 성공, 오류/경고 없음.
- 실제 로컬 방 UI의 6종을 실행해 양쪽 역할, 전체 프레임, 공통 시각 동기화를 관찰했다. 실사용자 방에 접속하거나 메시지를 보내지 않는 mock 모드였다.
- 수면의 400ms 간격 이미지에서 10,040개 픽셀의 분명한 변화를 확인했다. 벤치 4개의 실제 DOM 크기와 충돌선 버튼 제거도 확인했다.
- 캐릭터 미리보기의 실제 캔버스에서 하이파이브 접촉을 확인했다.
- `node scripts/check-social-actions.mjs`, `node scripts/check-garden-navigation.mjs`, TypeScript, 변경된 독립 모듈 ESLint 및 운영 빌드로 확인한다.
- 별도 기기의 실제 통화 중 네트워크 지연 검증은 수행하지 않았다.
