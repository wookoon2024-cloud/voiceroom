# 🎮 보이스룸 2D 픽셀 캐릭터 & 동작 스프라이트 제작 및 확장 가이드

이 문서는 새로운 캐릭터 스킨이나 새로운 동작(춤, 낚시, 박수, 다양한 감정표현 등)을 추가할 때, **기존 캐릭터들과 100% 비주얼 통일성 및 1:1 체구 스케일을 영구히 유지**할 수 있도록 정립된 표준 제작 및 자동화 파이프라인 명세서입니다.

---

## 📐 1. 표준 마스터 스프라이트 시트 규격 (1024 x 1024)

새로운 캐릭터를 추가하거나 기존 캐릭터의 전체 동작을 그릴 때는 **반드시 1장의 1024x1024 캔버스에 5개 행(Row)으로 구성된 마스터 시트**를 제작합니다. (배경색: `#00FF00` 순수 크로마 그린)

```
+-------------------------------------------------------------+
| Row 1: 정면 보행 4프레임 (Front Walk: 대기, 왼발, 스텝, 오른발) |
+-------------------------------------------------------------+
| Row 2: 후면 보행 4프레임 (Back Walk: 대기, 왼발, 스텝, 오른발)  |
+-------------------------------------------------------------+
| Row 3: 측면 보행 4프레임 (Side Walk: 대기, 왼발, 스텝, 오른발)  |
+-------------------------------------------------------------+
| Row 4: 솔로 액션 3종 (Sit 앉기, Lie 눕기, Jump 점프)           |
+-------------------------------------------------------------+
| Row 5: 소셜 상호작용 3종 (Handshake 악수, Hug 포옹, Kiss 뽀뽀) |
+-------------------------------------------------------------+
```

### 1) 규격 및 그리드 분할
* **캔버스 크기**: `1024 x 1024 px` (PNG 또는 고품질 JPG)
* **행(Row) 높이**: 행당 정확히 `204.8 px` (총 5개 행)
* **열(Col) 폭**:
  - Row 1 ~ 3 (보행): 열당 `256 px` (총 4개 열)
  - Row 4 ~ 5 (액션 / 인터랙션): 열당 `341.3 px` (총 3개 열)
* **배경색**: 단색 순수 크로마키 그린 (`#00FF00`, RGB `0, 255, 0`) — 그림자나 바닥 텍스처 없이 플랫하게 유지

## ⚖️ 3. 인게임 1:1 체구 스케일 보존 공식

인게임 광장(`lib/plaza.tsx`)에서 캐릭터가 눕거나 앉거나 점프할 때 **서 있을 때의 머리 크기와 체구가 1:1로 정확하게 유지**되도록 아래 박스 비율 규칙이 적용되어 있습니다:

```typescript
// 기준 단위: baseW = unit * s (화면 해상도 기반 표준 폭)

// 1. 서 있기 (기본 보행)
w = baseW;
h = baseW * 1.3125;

// 2. 눕기 (수면: 가로로 누워도 키가 유지되도록 폭 확장)
w = baseW * 1.85;
h = baseW * 0.95;

// 3. 앉기 (양반다리 착석: 머리 크기 1:1 유지 & 좌우 무릎 여백 확보)
w = baseW * 1.45;
h = baseW * 1.45;

// 4. 점프 (공중 도약: 귀나 머리가 상단에 잘리지 않도록 도약 높이 확장)
w = baseW * 1.45;
h = baseW * 1.75;
```

## 🚀 4. 원클릭 자동 변환 및 패키징 스크립트

새로운 캐릭터의 마스터 시트 이미지가 준비되면, 아래 명령 한 줄로 투명화 제거, 4x4 스프라이트 시트 패키징, 개별 액션 분리를 자동으로 수행합니다:

```bash
# 사용법: python scripts/process_character_spritesheet.py --char [캐릭터ID] --sheet [시트이미지경로]
python scripts/process_character_spritesheet.py --char cat --sheet path/to/cat_master.jpg
```

### 자동 생성되는 파일 위치:
1. `public/plaza/sheets/{char_id}.png` (인게임 4방향 4x4 보행 시트)
2. `public/plaza/actions/{char_id}_sit.png` (전용 1:1 앉기 도트)
3. `public/plaza/actions/{char_id}_lie.png` (전용 1:1 눕기 도트)
4. `public/plaza/actions/{char_id}_jump.png` (전용 1:1 점프 도트)
5. `public/plaza/actions/{char_id}_interact_handshake.png` (악수 도트)
6. `public/plaza/actions/{char_id}_interact_hug.png` (포옹 도트)
7. `public/plaza/actions/{char_id}_interact_kiss.png` (뽀뽀 도트)
8. `public/plaza/chars/{char_id}.png` (대표 정면 포트레이트)

## 💡 5. 향후 추가 동작(춤, 낚시, 인사 등) 확장 방법

새로운 동작을 추가할 때:
1. **마스터 시트 열(Column) 확장**:
   - `Row 4` 또는 신규 `Row 6`에 추가 동작(예: `dance`, `fish`, `clap`)을 배치합니다.
2. **`lib/plaza.tsx`에 포즈 등록**:
   - `PlazaPose` 타입에 `'dance' | 'fish'` 추가
   - `CharacterSprite`에서 `/plaza/actions/${safeId}_dance.png` 렌더링 매핑
   - `isDancing ? baseW * 1.45 : ...` 형태로 1:1 스케일 높이 지정
3. **`app/page.tsx` UI 메뉴에 버튼 추가**:
   - 감정표현 모달이나 퀵액션 바에 해당 동작 호출 함수 `handleMyPlazaPose("dance")` 연결
